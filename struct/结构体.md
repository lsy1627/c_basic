# 结构体

## 一、结构体是什么

把**不同类型**的数据打包成一个整体，当作一个变量使用 —— 这是 C 里造"新类型"的唯一手段。

对比数组：数组只能存**同类型**的元素；结构体可以自由组合。

```c
struct Student
{
    int id;        // 学号
    int age;       // 年龄
    char *name;    // 姓名
};
```

---

## 二、三种声明方式

### 1. 标准结构体（不推荐，啰嗦）

```c
struct Student { int id; int age; };

struct Student stu1;               // 每次都要写 struct
struct Student *p = &stu1;
```

### 2. 匿名结构体（**只能紧跟变量，不能单独用**）

```c
struct {
    int x;
    int y;
} a, b;      // 类型名丢了，只有 a、b 这两个变量能用
```

之后想再声明第三个就不行了 —— 因为**类型没有名字**。

### 3. `typedef` 起别名（写代码用这个）

```c
typedef struct Boy{
    int age;
} Boy;

Boy b1;                  // ✅ 不用再写 struct
```

> **易错点**：`typedef struct Boy{...} Boy;` 里的 `Boy` **可以省略**。
> 但**如果省略了，后面就再也无法单独声明该类型的指针**：
>
> ```c
> typedef struct { int age; } Boy;    // 匿名
> Boy b1;                              // ✅ 变量可以用
> struct Boy *p;                       // ❌ 编译错误，没有 tag 叫 Boy
> Boy *p = &b1;                        // ✅ 用 typedef 名
> ```

**最安全的写法**：匿名结构体 + typedef，或者两者都写全。

## 三、结构体的嵌套

一个结构体的成员可以是另一个结构体，访问时要**逐层访问**。

```c
typedef struct {
    int year;
    int month;
    int day;
} Birthday;

struct Student {
    int id;
    Birthday birthday;      // 嵌套生日
};

stu1.birthday.year = 2007;      // 逐层访问
```

**另一种嵌套方式**（匿名内嵌）：

```c
struct Student {
    int id;
    struct {
        int year;
        int month;
    } birth;
};

stu1.birth.year = 2007;         // 内层没起名，就少一层
```

## 四、指定初始化（推荐写法）

```c
struct Student stu1 = {
    .id = 1,
    .name = "lsy",
    .age = 18,
    .birthday = {.year = 2007, .month = 11, .day = 9}
};
```

**优点**：

1. 成员顺序变了也不用改初始化顺序，不会报错
2. 没写的成员自动补 0（普通写法下未初始化的成员是**垃圾值**）
3. 嵌套结构体也能指定初始化

对比全清零的简写：

```c
struct Student stu2 = {0};      // 所有成员置 0
```

## 五、结构体指针作函数参数

### 1. 访问符号：`.` 还是 `->`

| 对象类型 | 用什么访问 |
|---|---|
| 结构体**变量** | `.` |
| 结构体**指针** | `->` |

```c
stu1.age;      // 结构体变量 → 点
pStu->age;     // 结构体指针 → 箭头（等价于 (*pStu).age）
```

### 2. 为什么要传指针

**值传递会把整个结构体拷贝一份**：

```c
void f(Student s);      // ❌ 拷贝整个结构体，且函数内的修改不会传出去
void f(Student *s);     // ✅ 只传 8 字节地址，省内存且能改原数据
```

这也是**链表、动态数组**必须传指针的原因 —— 结构体里存着指针和数组，拷贝成本很高。

### 3. 函数返回结构体 vs 返回指针

```c
Student get_stu(void);          // 返回值：拷贝一份，可以安全返回局部变量
Student *get_stu(void);         // 返回指针：指向的内存必须由别人管（malloc 的）
```

## 六、结构体的整体赋值

**结构体之间可以直接赋值，会做逐成员的浅拷贝**：

```c
Student stu1 = {.name = "lsy", .age = 16, .score = 100};
Student stu2 = stu1;             // ✅ 直接拷贝
stu2.age = 18;                   // 改 stu2 不影响 stu1

Student arr[2] = {stu1, stu2};   // 数组初始化也可以
```

> ⚠️ **浅拷贝的坑**：成员里有指针时，拷贝的是**指针本身**，两个结构体指向**同一块内存**。
>
> ```c
> Student stu1 = {.name = "lsy"};    // name 指向字符串常量
> Student stu2 = stu1;
> stu2.name[0] = 'X';                // stu1.name 也变了！甚至可能改到只读段崩溃
> ```
>
> 要真正独立，必须再 `malloc` 一份并 `strcpy` 过去 —— 这就是**深拷贝**。

## 七、配合回调函数排序

把"比较规则"当参数传进去，同一套排序代码支持多种排序依据 —— 同 `qsort` 的思路。

### 1. 函数指针的写法

```c
int (*p)(Student*, Student*);      // p 是"指向函数的指针"
```

拆解：`p` 先和 `*` 结合 → `p` 是指针；再看括号里 → 它指向的函数返回 `int`，接收两个 `Student*`。

### 2. 完整例子

```c
// 比较函数：返回 1 表示需要交换
int by_age(Student *a, Student *b){
    return a->age > b->age;
}
int by_score(Student *a, Student *b){
    return a->score > b->score;
}

// 参数3是函数指针，由调用方决定按什么排
void sort(Student *s, int n, int (*p)(Student*, Student*))
{
    for(int i = 0; i < n; i++)
        for(int j = 0; j < n - i - 1; j++)
            if(p(&s[j], &s[j+1])){
                Student tmp = s[j];      // 结构体整体赋值当交换用
                s[j] = s[j + 1];
                s[j + 1] = tmp;
            }
}

sort(arr, 2, by_age);      // 按年龄排
sort(arr, 2, by_score);    // 按分数排
```

> 这个排序是**冒泡排序**，O(n²)；比较函数多调用一次就有函数开销，`qsort` 内部改用快排，是 O(n log n)。

## 八、sizeof 与内存对齐（了解）

```c
printf("%d\n", sizeof(Student));
```

结构体的大小**不等于各成员大小之和**，编译器会插入**填充字节**，让各成员按自身对齐要求排列（常见是按 4 字节或 8 字节）。

| 现象 | 说明 |
|---|---|
| 成员顺序**不影响**最终 `sizeof` 的对齐要求，但会影响填充总量 | 把大类型放前面能省空间 |
| 结构体末尾一定会有填充，保证数组中每个元素都对齐 | 这就是**柔性数组**不能放中间的原因 |

> 这个知识点考试常以"计算 `sizeof` 结果"的形式出现。

## 九、常见错误清单

| 错误 | 后果 |
|---|---|
| 结构体指针用 `.` 访问 | 编译错误 |
| 结构体变量用 `->` 访问 | 编译错误 |
| 忘了 `typedef` 就省略结构体 tag | 后面无法声明该类型的指针 |
| 局部结构体不做初始化 | 成员是栈上的垃圾值 |
| `char *name` 未赋值就用 `%s` 打印 | 野指针崩溃 |
| 值传递整个结构体 | 白拷贝，且改不到原数据 |
| 结构体含指针时"以为"整体赋值是深拷贝 | 两个变量共享内存 |
| `malloc` 的结构体不检查返回值 | 段错误 |
| 结构体里有指针成员，释放时只 `free` 外层 | **内存泄漏**（内层没释放） |
