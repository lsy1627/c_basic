## 二、线性表是什么

**由 n 个数据特性相同的元素构成的有限序列** —— 顺序表和链表都是它的实现方式。

### 四个特点

1. 存在唯一一个被称作 **"第一个"** 的元素
2. 存在唯一一个被称作 **"最后一个"** 的元素
3. 除第一个外，每个元素**只有一个前驱**
4. 除最后一个外，每个元素**只有一个后继**

### 关键区分：逻辑结构 vs 存储结构

| | 内容 |
|---|---|
| **线性表的逻辑结构** | "元素一个接一个"这个关系 —— 顺序表和链表**都有** |
| **存储结构** | 这种关系**怎么用内存表达** —— 顺序表用相邻地址，链表用指针 |

> 线性表 ≠ 顺序表。顺序表只是线性表的一种"存法"。

## 三、顺序表（Sequential List）

### 1. 定义

线性表的**顺序存储结构**：用一段**地址连续**的存储单元依次存放元素 —— 本质就是数组。

```c
#define MAXSIZE 100
typedef int ElemType;

typedef struct {
    ElemType data[MAXSIZE];   // 存放数据的数组
    int length;               // 当前元素个数（有效长度）
} SeqList;
```

| 成员 | 含义 |
|---|---|
| `MAXSIZE` | 物理容量，**定长**，装满就溢出 |
| `length` | 当前元素个数，范围 `[0, MAXSIZE]` |
| 合法元素 | `data[0] ~ data[length-1]` |

### 2. 动态分配版本

`MAXSIZE` 写死不够灵活，改成运行时申请：

```c
typedef struct {
    ElemType *data;   // ← 改成指针，指向堆上申请的空间
    int length;
} MemoryList;

MemoryList* initListMem(void)
{
    MemoryList *L = (MemoryList*)malloc(sizeof(MemoryList));  // 注意类型！
    if(L == NULL) return NULL;

    L->data = (ElemType*)malloc(sizeof(ElemType) * MAXSIZE);
    if(L->data == NULL){
        free(L);          // 先内后外，防泄漏
        return NULL;
    }
    L->length = 0;
    return L;
}
```

**数组版 vs 指针版**：

| | 数组版 `ElemType data[MAXSIZE]` | 指针版 `ElemType *data` |
|---|---|---|
| 要不要单独 malloc | ❌ 结构体自带 | ✅ 要，且要两次 |
| 释放 | `free(L)` 一句 | `free(L->data); free(L);` **先内后外** |
| `sizeof(L->data)` | 整个数组大小 | **只有 8**（一个指针）—— 大坑 |
| 容量 | 编译期定死 | 可以用 `realloc` 扩容 |

### 3. 基本操作（下标从 0 开始）

**按位置取值 O(1)**

```c
int GetElem(SeqList L, int i){
    if(i < 1 || i > L.length) return -1;   // 题面 i 从 1 开始
    return L.data[i - 1];                  // 代码从 0 开始 → i-1
}
```

**插入 O(n)**

```c
int Insert(SeqList *L, int i, ElemType e){
    if(L->length >= MAXSIZE) return 0;          // ① 满
    if(i < 1 || i > L->length + 1) return 0;    // ② 位置：1 ~ length+1
    for(int j = L->length; j >= i; j--)         // ③ 从后往前挪，倒序必须
        L->data[j] = L->data[j-1];
    L->data[i-1] = e;
    L->length++;
    return 1;
}
```

**删除 O(n)**

```c
int Delete(SeqList *L, int i, ElemType *e){
    if(i < 1 || i > L->length) return 0;        // ① 两端都要查
    *e = L->data[i-1];                          // ② 先存档，再搬
    for(int j = i; j < L->length; j++)          // ③ 从前往后挪
        L->data[j-1] = L->data[j];
    L->length--;
    return 1;
}
```

**按值查找 O(n)**

```c
int LocateElem(SeqList L, ElemType e){
    for(int i = 0; i < L.length; i++)
        if(L.data[i] == e) return i + 1;   // 返回序号（从 1）
    return 0;                              // 0 表示未找到
}
```

### 4. 时间复杂度

| 操作 | 复杂度 | 原因 |
|---|---|---|
| 访问第 i 个 | **O(1)** | 下标直接算地址 |
| 插入 / 删除 | **O(n)** | 平均挪一半元素 |
| 按值查找 | **O(n)** | 顺序比较 |
| 求表长 | **O(1)** | 读 `length` |

## 四、单链表（Singly Linked List）

### 1. 定义

线性表的**链式存储结构**：用**不要求连续**的存储单元存放元素，节点之间用**指针**串起来。

```c
typedef int ElemType;

typedef struct Node{        // ← 必须写 tag，否则 Node* 和 struct Node* 是两种类型
    ElemType data;          // 数据域
    struct Node *next;      // 指针域
} Node;
```

**局限性**：只能指向后继，**无法回头** —— 这是单链表的核心痛点，也是双链表存在的理由。

### 2. 头节点（哨兵）

```
head ┌─→ [1] → [2] → [3] → NULL
[0]──┘
```

| 概念 | 是什么 | 谁持有 |
|---|---|---|
| **头指针** | 指向第一个节点的指针变量 | 调用者 |
| **头节点** | 第一个节点，**不存有效数据** | 头指针指向它 |

**头节点带来的两个好处**：

1. 插入删除不用判断"是不是第一个节点"，所有情况统一成"改前驱的 next"
2. 空表和非空表统一表示：空表就是 `head->next == NULL`

**代价**：遍历必须 `p = node->next` 起步，否则会把哨兵的 0 打印出来（踩过这个坑）。

### 3. 基本操作

**初始化**

```c
Node* initList(void){
    Node *head = (Node*)malloc(sizeof(Node));
    if(head == NULL) return NULL;   // 别忘了检查
    head->data = 0;
    head->next = NULL;
    return head;
}
```

**头插法 O(1)**（顺序反转）

```c
void insertHead(Node* node, ElemType a){
    Node *p = (Node*)malloc(sizeof(Node));
    p->data = a;
    p->next = node->next;   // 新节点接住原来的后继
    node->next = p;         // 头节点指向新节点
}
```

**尾插法**（保持顺序，需要尾指针）

```c
Node* inserTail(Node* tail, ElemType a){   // 返回新的尾节点，供下次接着用
    Node *q = (Node*)malloc(sizeof(Node));
    q->data = a;
    q->next = NULL;
    tail->next = q;
    return q;
}
```

> 没有尾指针时每次都要 `get_tail()` 遍历找尾，建 n 个节点就是 **O(n²)**。

**按位置插入 O(pos)**

```c
int inserPos(Node* node, int pos, ElemType a){
    if(pos < 1) return 0;                    // 别忘了
    Node *p = node;
    for(int i = 0; i < pos - 1; i++){        // 走到 pos 的前驱
        p = p->next;
        if(p == NULL) return 0;              // 越界
    }
    Node *q = (Node*)malloc(sizeof(Node));
    q->data = a;
    q->next = p->next;                       // 先接后，再断前（顺序反了就断链）
    p->next = q;
    return 1;
}
```

**删除 O(pos)** —— 核心是"先存档，再破坏"

```c
ElemType delElm(Node* node, int pos){
    Node *p = node;
    for(int i = 0; i < pos - 1; i++){
        p = p->next;
        if(p == NULL) return 0;
    }
    Node *q = p->next;       // ① 抢救目标节点
    ElemType del = q->data;  // ② 存档数据
    p->next = q->next;       // ③ 前驱跨过它
    free(q);                 // ④ 现在才释放
    return del;
}
```

**反转链表 O(n)**（经典三指针）

```c
Node* reverseList(Node* node){
    Node *first = NULL;        // 反转后的尾节点，初始为 NULL
    Node *second = node->next; // 当前处理的节点
    Node *third;               // 保存后继

    while(second != NULL){
        third = second->next;  // ① 抢救后继
        second->next = first;  // ② 掉头
        first = second;        // ③ 前移
        second = third;
    }
    Node *head = initList();
    head->next = first;
    return head;
}
```

> **`first` 千万别初始化成 `node`（头节点）**：那样头节点也会参与反转，变成
> `1 ← H ← 1 ← 2 ← 3`，`H->next` 还是 1，而 `1->next` 又是 H，**成环**。

**释放整个链表**（先存档再 free）

```c
void releList(Node* node){
    Node *p = node->next;      // 跳过头节点
    while(p != NULL){
        Node *q = p->next;     // ① 抢救后继
        free(p);               // ② 销毁
        p = q;                 // ③ 前进
    }
    node->next = NULL;         // 让头节点回到"空表"状态
}
```

> 这是**清空**（头节点保留），不是**销毁**（头节点也释放）。

### 4. 复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 按位置查找 / 删除 | O(n) | 找位置要遍历 |
| **已知位置后插删** | **O(1)** | 只改两个指针 |
| 头插 | O(1) | 不需要遍历 |
| 尾插（有 tail） | O(1) | 直接接上 |
| 尾插（无 tail） | O(n) | 要遍历找尾 |

**关键认知**：链表的 O(n) 全花在**"找位置"**上，真正改指针永远是 O(1)。

## 五、顺序表 vs 链表

| | 顺序表 | 链表 |
|---|---|---|
| **空间** | 预先分配，会出现闲置或溢出 | 动态分配，按需申请 |
| **按位置访问** | **O(1)**，下标直接算 | **O(n)**，必须从头走 |
| **插入/删除** | O(n)，平均移动一半元素 | **O(1)**（找到位置后，只改指针） |
| 存储密度 | 高（无额外开销） | 每个节点多一个指针域 |
| 内存连续 | 需要一整块连续空间 | 不需要 |
| 缓存友好度 | 高 | 低（跳着访问） |

**适用情况**

- **用顺序表**：① 表长变化不大 ② 很少插入删除 ③ 经常按位置访问
- **用链表**：① 表长变化大 ② 频繁插入删除 ③ 不需要随机访问

> 顺序表用"访问慢"换来了"插删快"和"容量灵活"，链表反之。

## 六、快慢指针专题

链表题里"尽可能高效"几乎都靠双指针 —— 把 O(n) 遍历压成**一趟**。

### 1. 固定间距型：倒数第 k 个

```c
int findNodeFS(Node* node, int k){
    if(node == NULL || k < 1) return 0;
    Node *fast = node->next;
    Node *slow = node->next;

    for(int i = 0; i < k; i++){          // ① fast 先走 k 步
        if(fast == NULL) return 0;       //    长度不足 k
        fast = fast->next;
    }
    while(fast != NULL){                 // ② 同步走，差距恒为 k
        fast = fast->next;
        slow = slow->next;
    }
    return slow->data;                   // ③ fast 到 NULL，slow 即倒数第 k 个
}
```

**为什么对**：fast 走 `len` 步，slow 走 `len - k` 步 → 停在第 `len-k+1` 个 = 倒数第 k 个。

### 2. 速度差型：找中点 / 判环

**找中间节点**（偶数取偏后）

```c
void remMidNode(Node* node){
    Node *fast = node->next;
    Node *slow = node;
    while(fast != NULL && fast->next != NULL){
        slow = slow->next;
        fast = fast->next->next;
    }
    Node *p = slow->next;      // slow 是中间节点的前驱
    slow->next = p->next;
    free(p);
}
```

**判断有环（Floyd 判圈）**

```c
int isCycle(Node* node){
    Node *fast = node, *slow = node;
    while(fast != NULL && fast->next != NULL){
        fast = fast->next->next;
        slow = slow->next;
        if(fast == slow) return 1;   // 追上 → 有环
    }
    return 0;
}
```

**为什么一定追上**：进环后 fast 每步比 slow 多走 1 个节点，相当于以速度 1 **逼近**，不会跨过去。

### 3. 找环的入口

```c
Node* cycleStart(Node* head){
    Node *fast = head, *slow = head;
    while(fast && fast->next){
        fast = fast->next->next;
        slow = slow->next;
        if(fast == slow) break;
    }
    if(fast == NULL || fast->next == NULL) return NULL;

    slow = head;                  // 一个回起点
    while(slow != fast){          // 同速前进，再次相遇即入口
        slow = slow->next;
        fast = fast->next;
    }
    return slow;
}
```

**推导**（头到入口 `a`，入口到相遇点 `b`，环长 `L`）：
fast 走了 `a+b+L`，slow 走了 `a+b`，且 `fast = 2·slow`
→ `a + b + L = 2(a+b)` → **`a = L - b`**
即"头到入口"等于"相遇点绕回入口"，所以两指针同速再走必在入口相遇。

### 4. 起点重定位型：两链表公共后缀

**注意区分两种题**：

| 题型 | 特征 | 解法 |
|---|---|---|
| **两链表相交**（Y 字形） | 交点后**合成一条** | 换道法：`p = p ? p->next : h2` |
| **两链表公共后缀** | 后缀节点**共享**，但前面各自独立 | **先对齐长度，再同步走** |

`train2.c` 是后者：

```c
Node* findPub(Node* str1, Node* str2){
    Node *p = str1->next;
    Node *q = str2->next;
    int n1 = 0, n2 = 0;
    for(Node *t = p; t != NULL; t = t->next) n1++;
    for(Node *t = q; t != NULL; t = t->next) n2++;

    // 让长的先走长度差步 —— 必须移动 p、q 本身，不能移动副本
    for(int i = n1 - n2; i > 0; i--) p = p->next;
    for(int i = n2 - n1; i > 0; i--) q = q->next;

    while(p != NULL && q != NULL){
        if(p == q) return p;      // 比"节点地址"，不是比 data
        p = p->next;
        q = q->next;
    }
    return NULL;
}
```

**必须比指针**：题目说后缀是**共享同一片存储空间**，所以公共起点是同一个 `Node*`。比字符会把 "abc" 和 "xbc" 误判成有公共后缀。

### 5. 选型速查

| 问题 | 指针关系 | 关键代码 |
|---|---|---|
| 倒数第 k 个 | fast 领先 k 个 | fast 先走 k 步，再同步 |
| 找中点 | 速度比 2:1 | `fast = fast->next->next` |
| 判环 | 速度比 2:1 | 重合即有环 |
| 环入口 | 速度比 2:1 | 相遇后一个回原点再同步 |
| 两链交点 | 起点换道 | `p = p ? p->next : h2` |
| 两链公共后缀 | 先对齐长度 | 长链先走 `len差` 步 |

## 七、练习题汇总

### train1：倒数第 k 个节点

- **题目**：带头节点单链表，找出倒数第 k 个节点的 data，成功返回 1 否则 0，要求高效
- **两种解法**：① 先算长度再走位（2 趟）② 快慢指针（1 趟，标准答案）
- **踩过的坑**：
  1. **`q` 起点用头节点** → 结果差一位（倒 2 变成倒 3）。头节点**不算数据**，必须 `q = node->next`
  2. **少写 `*`**：`a = q->data;` 应为 `*a = q->data;` → `k` 一直是 0
  3. 调用端判断 `!= 0` vs `== 1` 反了，导致直接 return
  4. `k < 1` 没检查 → `k` 为负时指针走出链表崩溃

### train2：两链表公共后缀

- **题目**：找 `loading` 和 `being` 共同后缀 `ing` 的起始节点 `i`
- **核心**：先对齐长度再同步走，**比指针**
- **踩过的坑**：
  1. **测试数据不满足题目前提**：两条链表各自 `insertHead` 建了一遍，后缀不是同一批节点 → 指针永不相等 → 恒返回 0。正确做法是让 `str1` 的尾部**指向** `str2` 的 `ing` 节点
  2. **对齐时移的是副本**：`m = p; m = m->link;` → `p` 根本没动，后面并排走必然走空崩溃
  3. **比字符而非比指针**：`while(p->data != q->data)` 会误判
  4. 函数名拼写 `inserTail` → `insertTail`（隐式声明成 int，赋值给 `Node*` 报错）
  5. `while` 无 NULL 保护

### train3：删除绝对值重复的节点

- **题目**：`|data| ≤ n`，只保留第一次出现，删除其余绝对值相等的节点
- **解法**：**空间换时间** —— 开一个 `int tem[n+1]` 当标记数组，`tem[abs(data)]` 为 1 说明出现过
- **复杂度**：时间 **O(n)**（一趟），空间 **O(n)**（辅助数组）
- **对比**：暴力双重循环是 O(n²)，时间省下来了但费了 n+1 个 int
- **要点**：
  - 需要 `#include <stdlib.h>` 用 `abs()`
  - `p` 停在**待删节点的前驱**，删除时 `p->next = q->next; free(q);` 且 **`p` 不前移**
  - 保留时 `p = p->link` 才前移

### train4：重排 `a1 an a2 an-1 ...`

- **题目**：`L = (a1, a2, ..., an)` → `L' = (a1, an, a2, an-1, a3, an-2, ...)`，要求**空间 O(1)**
- **三步走**：
  1. **找中点**：快慢指针，`slow` 停在前半段末尾
  2. **反转后半段**：三指针反转，`slow->next = NULL` 把链表切成两条
  3. **交叉合并**：`p1`（前半）、`q1`（后半反转后的头）交替穿插
- **复杂度**：时间 O(n)，空间 **O(1)**（只用几个指针变量）
- **踩过的坑**：忘记 `slow->next = NULL` 断链 → 后半段反转时和前半段连在一起，成环

## 八、常见错误清单

### 顺序表

| 错误 | 后果 |
|---|---|
| 插入遍历用**正序**移动元素 | 后面的元素被前面的覆盖，数据错乱 |
| 删除条件写 `pos < L->length` | **删不掉最后一个元素**，应 `pos <= L->length` |
| 删除时先 `length--` 再取 `data[pos-1]` | 取到的是**被覆盖后**的值，必须**先存档** |
| 越界检查只查上界不查下界 | `pos = 0` 时 `data[-1]` 越界写 |
| `findElem` 的 `while` 没有 `i < length` | 找不到时**死循环 / 越界** |
| 定义结构体后又另起一个 `MemoryList` | 两个类型 `length` 偏移不同，函数间混用即越界 |
| `malloc(sizeof(SeqList))` 给了 `MemoryList*` | 大小对不上（404 vs 16），浪费或溢出 |

### 单链表

| 错误 | 后果 |
|---|---|
| 遍历从 `node` 而非 `node->next` 起步 | 打印出头节点的 0 / 位置全差一位 |
| `p = p->next` 前不判空 | 段错误 |
| `free(p)` 后再读 `p->next` | 悬垂指针（use after free） |
| 头插法忘写 `p->next = node->next` | 新节点指向 NULL，整条链表丢失 |
| 反转时 `first` 初始化成 `node` | 头节点参与反转，**成环** |
| 按位置插入忘 `pos < 1` | 前驱不存在，行为不可预期 |
| `typedef struct{...}Node;` 缺 tag | 每处 `Node*` ↔ `struct Node*` 报 `-Wincompatible-pointer-types` |
| 不同 `.c` 文件里互相调用函数 | 隐式声明 + 链接失败，跨文件要 `#include` 头文件 |
| 比较公共后缀时比 `data` | 字符相同但节点不同，误判 |
| 对齐长度时移动了副本 `m` | 主指针没动，逻辑失效 |
| 从头到尾没有 `free` | 内存泄漏 |

### 通用

| 错误 | 说明 |
|---|---|
| `malloc` 后不检查 `NULL` | 内存不足时直接解引用 |
| 函数需要"带出"数据却用值传递 | 形参改了，实参没变（`ElemType a` 应为 `ElemType *a`） |
| 返回值既当"状态"又当"数据" | 成功返回 1、失败也返回 1 时无法区分 |
| 加了 `-Wall` 还不看警告 | 大量错误（类型不匹配、变量未用）编译器都会点出来 |
