## 二、指针是什么

指针是一个**保存地址的变量**。变量的地址就是它内存位置的编号，`*` 的作用就是"通过地址找到那块内存"。

```c
int a = 10;      // a 是 int 变量
int *p = &a;     // p 是 int 指针，内容是 a 的地址
*p = 100;        // 通过 p 找到 a，把它改成 100
```

### `*` 的两种含义（最易混淆点）

| 场景 | 写法 | 含义 |
|---|---|---|
| **定义时**前面有类型 | `int *p;` | 声明 p 是一个"指向 int 的指针" |
| **使用时**前面没有类型 | `*p` | 解引用，取 p 指向的内存里的值 |

> 记忆：`int *p` = `int* p`（"类型是 int 指针"）；`*p = 5` 里的 `*` 是运算符。

### 类型必须匹配

**指针的类型一定要和它指向的变量类型一致**——编译器靠类型决定一次读写多少字节。

```c
char b = 't';
char *p1 = &b;   // 对：char 指针指 char，步长 1 字节
// int *p2 = &b; // 错：类型不匹配，编译器会警告，实际是危险的
```

64 位系统下**所有指针都是 8 字节**，但步长不同：

```c
sizeof(int*)   // 8 —— 大小都一样
sizeof(char*)  // 8
// 但步长（p+1 走多远）由类型决定：int* 跳 4 字节，char* 跳 1 字节
```

## 三、指针运算

| 运算 | 写法 | 含义 |
|---|---|---|
| 解引用 | `*p` | 取 p 指向的值 |
| 取地址 | `&a` | 取变量 a 的地址 |
| 加减 | `p + n` | 移动 n 个元素（不是 n 个字节） |
| 自增/自减 | `p++` / `p--` | 指针本身移动 |
| 解引用自增 | `(*p)++` | p 不动，p 指向的值加 1 |
| 两指针相减 | `p - q` | 相差多少个元素（可为负，可判断先后） |

### 运算符优先级陷阱

```c
x = ++*p2;   // 等价于 x = ++(*p2)  → c 加 1，p2 不动
z = *p2++;   // 等价于 z = *(p2++)  → p2 先加 1，再对*旧值*解引用
```

`*` 优先级高于 `++`，所以 `*p++` = `*(p++)`。这是**面试常考点**。

### 用指针大小比较位置

```c
while(start < end){      // 两个 int* 可以直接比大小（同一数组内）
    char temp = *start;
    *start = *end;
    *end = temp;
    start++;
    end--;
}
```

## 四、空指针与野指针

| 名称 | 含义 | 后果 |
|---|---|---|
| **空指针** | `int *p = NULL;` 地址为 0，不指向任何内存 | 解引用直接崩溃（段错误） |
| **野指针** | 未初始化的指针，内容是随机垃圾值 |  unpredictable，可能崩溃或改坏别的数据 |
| **悬垂指针** | `free` 之后没置 `NULL` 的指针 | 指向已释放内存，继续用 = UB |

### 合法使用指针的两种内存来源

1. **系统分配的（栈内存）**

   ```c
   int a;
   int *p = &a;
   ```

2. **用户申请的（堆内存）**

   ```c
   int *p = (int*)malloc(sizeof(int));  // 返回 void*，必须强转
   if(p == NULL) return -1;             // 必须检查
   // ... 使用 ...
   free(p);                            // 不释放 = 内存泄漏
   p = NULL;                           // 释放后置空，防野指针
   ```

> 详见同仓库 `dynamic_memory/动态内存.md`。

## 五、指针作函数参数（为什么函数能修改实参）

C 语言**值传递**：参数是拷贝的副本。但指针的副本里存的还是同一个地址，所以通过指针修改 == 修改原变量。

```c
void exchange(int *p1, int *p2){
    int temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

int num_1 = 1, num_2 = 2;
exchange(&num_1, &num_2);   // 传地址 → 成功交换
```

如果传 `exchange(num_1, num_2)`（值），只会交换两个副本，外面毫无变化。

**对数组天然成立**：数组名传进函数时退化成指针，所以函数里的 `p[i]` 就是调用方的 `arr[i]`。

## 六、指针与数组

### 1. 数组 vs 指针

```c
char str[32] = "helloworld";   // 数组：32 字节真实空间
char *p = "helloworld";        // 指针：只存 8 字节地址

sizeof(str)   // 32 —— 整个数组的字节数
sizeof(p)     // 8  —— 存地址的字节数
```

| | 数组 | 指针 |
|---|---|---|
| `sizeof` | 整个数组大小 | 指针自身大小（8） |
| 可否 `++` / `str++` | ❌ 数组名是常量，始终指向首元素 | ✅ 可以移动 |
| 内存归属 | 栈/全局区，名字即首地址 | 指向别处 |

### 2. `str` 与 `str[0]` 永远等价

```c
str[i]  ≡  *(str + i)  ≡  *(p + i)
```

### 3. 数组作为函数参数 → 退化成指针

```c
void f(int a[], int len);   // 等价于 void f(int *a, int len)
```

⚠️ 因此**函数内部拿不到数组真实长度**，必须额外传 `len`。

### 4. 指针数组 vs 数组指针

```c
char *str[] = {"hello", "world"};  // 指针数组：数组里每个元素是指针
str[0]  → "hello"

char (*arr)[5];                    // 数组指针：指向整个数组的指针（很少用）
```

> 快速区分：看 `[]` 和 `*` 谁离名字近。`char *str[]` → 名字 `str` 挨着 `[]`，所以是**数组**；元素类型是 `char *`。

### 5. `const` 修饰

```c
const char *p = "abc";   // 指向只读数据，不能通过 p 修改
char * const q = arr;    // q 本身是常量（不能指向别处），但 *q 可改
```

## 七、指针与函数

### 1. 函数指针：指向函数的指针

```c
void (*p4)(int *, int *);   // 返回 void，参数是两个 int*
p4 = exchange;
p4(&num_1, &num_2);         // 等价于 exchange(&num_1, &num_2)
```

读法：`(*p4)` 是"一个函数"，前面的 `void` 是返回值，`(int*, int*)` 是参数表。

### 2. 指针函数：返回指针的函数

```c
char *my_strchr(char *s, char c);
```

⚠️ **不能返回局部变量的地址**——函数返回后栈帧销毁，地址立即失效。

```c
char *bad(){
    char buf[32] = "hi";
    return buf;      // 错！buf 已随栈帧销毁
}
```

正确做法有两条：

1. 返回**入参**的地址（属于调用方，如 `tran1_delete.c` 的做法）
2. 用 `malloc` 申请后返回（**必须由调用者 `free`**，见 `train5_add_h_t.c`）

### 3. 回调函数：把函数名当参数传

作用：**同一个算法，靠换一个函数改变行为**。

```c
int less(int x, int y)    { return (x > y) ? 1 : 0; }  // 升序
int greater(int x, int y) { return (x < y) ? 1 : 0; }  // 降序

// 返回 1 表示"要交换"——把判断权交给外部
void sort(int *a, int len, int (*p)(int, int)){
    for(int i = 0; i < len-1; i++)
        for(int j = 0; j < len-i-1; j++)
            if(p(a[j], a[j+1])){
                int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
            }
}

sort(str1, 10, greater);   // 传 different 函数 → 不同排序结果
```

> `qsort()` 就是标准库里的回调函数典范。

## 八、本目录代码里的通用套路

### 套路 1：保存首地址，遍历用临时指针

```c
char *q = p;                  // 备份首地址
while(*p != '\0'){ ... p++; } // p 一路往前走
return q;                     // 返回起点而不是终点
```

### 套路 2：双指针原地改写（p 读、r 写）

```c
char *q = p, *r = p;          // q 记住起点供返回，r 是写指针
while(*p != '\0'){
    if(*p != ' ') *r++ = *p;  // 条件满足才写
    p++;                      // 读指针始终前进
}
*r = '\0';                    // 补结束符
return q;
```

> 因为 `r` 永远不跑到 `p` 前面，所以**原地覆盖是安全的**。

### 套路 3：首尾对撞

```c
char *start = src, *end = src;
while(*end != '\0') end++;
end--;                        // 从 '\0' 退一格
while(start < end){ swap(*start, *end); start++; end--; }
```

### 套路 4：输出参数（返回两个东西）

```c
char *Find_Max_Pub(char *src, char *des, int *out_len);
// 返回值 → 指向公共子串的指针（可能为 NULL）
// *out_len → 公共长度，通过指针回写给调用方
```

### 套路 5：输入整行字符串

```c
char *str = (char*)malloc(128);
scanf("%[^\n]", str);   // 遇到换行停止，空格照收（比 %s 强）
```

`%[^\n]` = 匹配任意"非换行"字符集。

## 九、易错点清单

| # | 易错写法 | 问题 | 正确写法 |
|---|---|---|---|
| 1 | `int *p; *p = 5;` | 野指针，地址是垃圾值 | `int a; int *p = &a; *p = 5;` |
| 2 | `p = p2 + 1; free(p);` | 释放了非原始指针 | `free(p2);` |
| 3 | `char buf[3]; strcpy(buf, "hello");` | 越界，buf 只能放 2 字符 + `\0` | 数组开够，或用 `malloc` |
| 4 | `char *p = buf; str++;` | 数组名不可自增 | `p++;` |
| 5 | 传值给需要改原变量的函数 | 值传递只改副本 | 传 `&x` |
| 6 | `p = realloc(p, n);` | 失败返回 NULL 覆盖旧地址 → 泄漏 + 野指针 | 用临时指针接，检查后再赋值 |
| 7 | 函数返回局部数组地址 | 栈帧销毁后失效 | 返回入参地址或 `malloc` 的空间 |
| 8 | 用 `strlen()` 却没 `#include <string.h>` | 隐式声明，C99 后是错误 | 补头文件 |
| 9 | 判断字符串结束写成 `*p == '0'` | 字符 `'0'` 不是结束符 | `*p == '\0'` |
| 10 | 双向链表/字符串头插 p = 新结点 | 丢失旧头 | `新->next = 头; 头 = 新;` |

/* 1. mystrlen / mystrcat */
int mystrlen(const char *s){
    const char *p = s;
    while(*p != '\0') p++;
    return (int)(p - s);            // 指针相减 = 元素个数
}

char *mystrcat(char *dest, const char *src){
    char *p = dest;
    while(*p != '\0') p++;          // 先走到 dest 末尾
    while(*src != '\0') *p++ = *src++;
    *p = '\0';
    return dest;
}

/* 4. 回调：统一接口 */
void to_upper(char *s){ while(*s){ if(*s>='a'&&*s<='z') *s -= 32; s++; } }
void to_lower(char *s){ while(*s){ if(*s>='A'&&*s<='Z') *s += 32; s++; } }
void reverse(char *s){ char *e = s; while(*e) e++; e--; while(s < e){ char t=*s; *s=*e; *e=t; s++; e--; } }
void process(char *s, void (*f)(char *)){ f(s); }
/* 用法: process(str, to_upper); */

/* 5. 字符串替换 */
char *str_replace(char *src, const char *old, const char *new_str){
    char *buf = (char*)malloc(1024);
    if(buf == NULL) return NULL;
    char *w = buf, *s = src, *n = old;
    int old_len = 0;
    while(*n) { old_len++; n++; }
    if(old_len == 0) return buf;
    while(*s){
        char *t = s; int i = 0;
        while(i < old_len && *t && *t == old[i]){ t++; i++; }
        if(i == old_len){ const char *q = new_str; while(*q) *w++ = *q++; s = t; }
        else *w++ = *s++;
    }
    *w = '\0';
    return buf;
}

/* 6. 回文判断 */
int is_alpha(int c){ return (c>='a'&&c<='z') || (c>='A'&&c<='Z'); }
int to_lo(int c){ return (c>='A'&&c<='Z') ? c + 32 : c; }
int is_palindrome(const char *s){
    const char *l = s, *r = s;
    while(*r) r++;
    r--;
    while(l < r){
        while(l < r && !is_alpha(*l)) l++;
        while(l < r && !is_alpha(*r)) r--;
        if(to_lo(*l) != to_lo(*r)) return 0;
        l++; r--;
    }
    return 1;
}

/* 7. my_strstr */
const char *my_strstr(const char *hay, const char *needle){
    if(*needle == '\0') return hay;
    const char *p;
    for(p = hay; *p; p++){
        const char *a = p, *b = needle;
        while(*a && *b && *a == *b){ a++; b++; }
        if(*b == '\0') return p;
    }
    return NULL;
}

/* 8. 原地去重 */
char *remove_dup(char *src){
    char *r = src, *p = src;   // r = 已保留区末尾
    while(*p){
        char *q = src;
        int seen = 0;
        while(q < r){ if(*q == *p){ seen = 1; break; } q++; }
        if(!seen) *r++ = *p;
        p++;
    }
    *r = '\0';
    return src;
}

/* 9. 第一个重复元素 */
int *find_duplicate(int *arr, int n){
    for(int i = 0; i < n; i++)
        for(int j = i + 1; j < n; j++)
            if(arr[i] == arr[j]) return &arr[j];   // 注意：返回内部地址，不用 free
    return NULL;
}

/* 10. 最长单词 */
const char *longest_word(const char *s, int *len){
    const char *best = NULL, *p = s;
    int best_len = 0;
    while(*p){
        while(*p == ' ') p++;
        const char *ws = p;
        while(*p && *p != ' ') p++;
        int l = (int)(p - ws);
        if(l > best_len){ best_len = l; best = ws; }
    }
    *len = best_len;

        for(int j = 0; j < len-i-1; j++)
            if(cmp(&a[j], &a[j+1]) > 0){ int t=a[j]; a[j]=a[j+1]; a[j+1]=t; }
}
