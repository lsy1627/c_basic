# 数据结构与算法学习路线

> 起点：已掌握指针、数组、结构体、函数指针、动态内存分配
> 原则：**每学一个数据结构，立刻手写一遍并解决一个真实小问题**，不要只看书

## 阶段 1：线性结构（3-4 周）

### 1.1 线性表 / 数组（3-5 天）
- 已有基础：定义、遍历、下标
- 待补：插入、删除、越界、时间复杂度概念
- 练习：自己实现一个**能自动扩容的动态数组**（就是 `realloc` 那套翻倍扩容）

### 1.2 链表（1-1.5 周）← 数据结构第一关
- 类型：单链表、双向链表、循环链表
- **必须手写**：创建、插入、删除、查找、反转、合并、求中间节点、释放
- 经典题：两数相加（链表）、删除倒数第 N 个节点、判断链表是否有环

### 1.3 栈（1 周）
- 两种实现：数组实现 + 链表实现各一遍
- 应用：括号匹配、表达式求值、进制转换
- 经典题：用两个栈实现队列、**最小栈**（O(1) 取最小值）

### 1.4 队列 / 双端队列（3-5 天）
- 循环队列（注意"假溢出"）
- 应用：滑动窗口、生产者消费者
- **树的层序遍历**会用到这里

## 阶段 2：查找与排序（2-3 周）

### 2.1 查找（1 周）
- 顺序查找、二分查找（吃透 `lo/mid/hi` 的收敛边界）
- **哈希表**：自己写一个，链地址法解决冲突

### 2.2 排序（1-1.5 周）
- 已有：冒泡排序（见 `pointer/pointer_basic.c`）
- 待学：选择、**快排**、归并、堆排
- 快排的 partition 思想 + 递归必须能默写
- 概念：稳定性、比较排序下界 `O(n log n)`

---

## 阶段 3：树与图（4-6 周）← 难度陡增，留足时间

### 3.1 树 / 二叉树（2-3 周）
- 遍历：前序 / 中序 / 后序 —— **递归和迭代都要会**
- BST：插入、查找、删除
- 经典题：树高、翻转树、对称树、最近公共祖先、树的最大路径和
- 进阶：线段树、平衡树（先理解概念，代码后看）

### 3.2 图（2-3 周）
- 存储：邻接矩阵 vs 邻接表
- 遍历：DFS、BFS
- 最短路：Dijkstra、BFS（无权图）
- 经典题：岛屿数量、课程表、拓扑排序

### 3.3 动态规划（2-3 周）
- 先吃透"状态定义 + 状态转移"这个套路
- 题目：爬楼梯、最大子数组和、背包问题、编辑距离

## 学习方法（比路线本身更重要）

| 做法 | 说明 |
|---|---|
| **先手写再看书** | 看完觉得懂了 = 没懂。关掉资料自己写一遍 |
| **每题三遍** | 第一遍照着写 → 第二遍想清楚为什么 → 第三遍从零默写 |
| **写测试用例** | 必测边界：空、单元素、重复元素、逆序、全相同 |
| **记模板** | 快排、二分、DFS、BFS 的模板要能默出来 |
| **每天一题** | 比周末突击 8 小时有效得多 |
| **空指针/失败路径** | 沿用你现在的习惯：malloc 后检查、free 后置 NULL、越界前想边界 |

## 建议的启动方式

从 **单链表** 开始，第一步只做四件事：

1. 创建链表（尾部追加）
2. 插入一个节点
3. 删除一个节点
4. 遍历打印 + 释放全部节点

这四个函数写熟、测试用例写全（空链表、单节点、删头删尾），链表这一关就算过了。
建议存成 `algorithm/ds1_list.c` 这样的文件，和现在 `pointer/`、`struct/` 的习惯保持一致。
